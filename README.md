# Технофургон: три концепта главной страницы

Быстрые наброски главной страницы для сайта tehnofurgon.ru. Это не готовый сайт: финальный дизайн будет отрисован вручную.

Смотреть: https://takedown-desing.github.io/tehnofurgon-homepage-redesign/

| Вариант | Что внутри | Ссылка |
|---|---|---|
| 1. Светлый каталог | Светлый фон, фотографии компании, цена «от» на каждой карточке, форма с выбором изделия | `/v1/` |
| 2. Строгий производственный | Тёмная шапка, крупный первый экран, восемь направлений в одной сетке | `/v2/` (на телефоне открывается `/v2/mobile.html`) |
| 3. Тёмный имиджевый | Тёмная страница, единый стиль съёмки, блок «Подберите решение». Изображения каталога сгенерированы нейросетью как пример стиля | `/v3/` |

Все три варианта адаптивные: открываются на компьютере, планшете и телефоне.

## Откуда данные

Цены, отзывы, контакты и фотографии изделий взяты с действующего сайта компании. На фотографиях скрыты номера автомобилей и посторонняя реклама. Формы в набросках ничего не отправляют. Страницы закрыты от индексации (`noindex`).

## Структура

```
index.html        обзор трёх вариантов
v1/ v2/ v3/       страницы вариантов
assets/photos/    фотографии с сайта компании
assets/ai/        сгенерированные изображения для варианта 3
assets/brand/     логотип
assets/preview/   превью для обзорной страницы
```
